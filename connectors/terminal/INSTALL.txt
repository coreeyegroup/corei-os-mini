COREI OS MINI - Terminal readiness kit 0.6.2

STATUS: LOCAL DIAGNOSTICS ONLY. NO COREI VPS CONNECTION OR ORDER EXECUTION.
Source files are supplied, not compiled .ex4/.ex5 binaries. Compilation and terminal
compatibility must be verified in MetaEditor on the actual terminal computer.

WINDOWS
1. Download the kit from Connector profiles > Terminal installation. Extract it.
2. In the intended MT4/MT5 terminal, use File > Open Data Folder. Copy that path.
3. Open PowerShell in the extracted kit folder. Run, using your actual data folder:
   .\install-terminal.ps1 -Platform MT5 -DataFolder "C:\your actual terminal data folder"
   Use MT4 for MT4. No administrator rights should be needed.
   If script policy blocks it, use the manual method below or your approved local
   script policy. Do not disable system-wide execution policy.

UBUNTU / WINE
1. Extract the kit on the computer running the terminal (which may differ from the VPS).
2. In that Wine terminal use File > Open Data Folder. Locate the matching Linux path
   in its Wine prefix; do not assume another terminal's installation directory.
3. Run:
   bash install-terminal.sh MT5 "/actual/Linux/path/to/terminal/data/folder"
   Use MT4 for MT4. Run as the terminal owner, without sudo.

MANUAL METHOD (BOTH SYSTEMS)
Copy COREIOSMiniTerminalCheck.mq5 into MQL5/Experts/COREIOSMini, or the .mq4 file
into MQL4/Experts/COREIOSMini, within that terminal's data folder. Preserve any
existing file before replacement. Never overwrite broker config/servers.dat files.

COMPILE / ATTACH / CHECK
1. Open the installed source in the terminal's MetaEditor. Press F7. Require 0 errors.
2. Refresh Navigator > Expert Advisors; attach COREIOSMiniTerminalCheck to a chart.
   Do not replace an existing strategy EA on its chart; use a separate chart.
3. Set InstanceLabel to your terminal-instance label, ExpectedLogin to the broker
   account number, and ExpectedServer to the exact broker server name.
4. Read the Experts log. LOCAL_CHECK should report identity=MATCH if these values
   match the terminal account. VPS=NOT_CONNECTED is expected in this release.
5. A quote timestamp can be cached. It does not prove fresh data, verified identity
   at the VPS or any successful network connection. The check repeats every 30 seconds.
6. No DLL imports, WebRequest permission, API keys or broker passwords are needed
   by this checker. Keep automated trading permission disabled for this checker;
   if a terminal policy prevents it from running, inspect that policy locally.

STOP / REMOVE
Remove the EA from the chart. Then delete only COREIOSMiniTerminalCheck.mq4/.mq5
and its .ex4/.ex5 compiled file from Experts/COREIOSMini if no longer needed.
Source updates require recompilation and reattachment. Existing compiled binaries
are not replaced by the installer, so do not assume copying source updates a running EA.
Installers preserve existing source with a timestamped backup.

PRIVACY
Diagnostics are printed only to the local terminal log. Account ID, broker server
and instance label may appear there; redact personal identifiers before sharing.
No secrets or broker/server files are included in the kit or sent to the VPS.

NEXT CAPABILITY
The authenticated outbound HTTPS bridge will be a separate release with pairing,
server-side account verification, heartbeat, quote ingestion and reconnect handling.
Installing this kit does not set a workstation status to connected.
