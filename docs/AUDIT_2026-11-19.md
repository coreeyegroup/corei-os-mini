# End-to-end audit, 19 Nov 2026 — market data to execution

**Purpose.** The owner asked for a check from the beginning of the flow to execution: "still n8n format is not
implemented … many incomplete features, options and control … execution is not yet build". This records what was
checked, each gap found, what was done (release 0.51.0) and what is still open. Labels: **Fixed** (built and tested),
**Open** (not yet built, with the reason).

## Flow checked

1 Market data → 2 Features → 3 Signals → 4 Strategy → 5 Risk → 6 Portfolio → 7 Execution → 8 Post-trade, on paper,
with the backend suite (every stage end to end against a test database) and the workstation UI suites.

## Gaps and what was done

| # | Stage | Gap | Status |
|---|---|---|---|
| 1 | All | Calculations were formula text; none could be opened as nodes and wires (the n8n pattern asked for). | **Fixed** — graph canvas in every stage (Signals › Signal graphs; *Calculation graphs* in Market intelligence, Strategies, Risk, Portfolio, Execution, Post-trade). |
| 2 | 3 | Library signals could not be inspected step by step with numbers, copied or changed without code. | **Fixed** — 12 built-in signal graphs equal to the code (1e-9, every bar); copy, edit, check, propose, approve (four-eyes). |
| 3 | 3 | A changed formula could not be used live. | **Fixed** — bind an approved graph to a signal definition; board, flips, explain, correlation, research use it. |
| 4 | 4 | A strategy could only use the fixed algorithms. | **Fixed** — algorithm *Calculation graph* runs an approved, pinned strategy-rule graph in the runtime and the backtest (backtest equal to the cent). |
| 5 | 2 | Features were not visible as graphs. | **Fixed** for 6 features (equal to the feature engine); the rest is Open (phase 6). |
| 6 | 7 | No execution algorithms: every decision went to the market as one order. | **Fixed** — TWAP, VWAP, POV, iceberg; price cap; pause / resume / cancel; from a ticket or from the decision queue. |
| 7 | 7 | A working order could not be amended (only cancelled). | **Fixed** — amend limit / stop price, SL / TP, smaller paper quantity; MT5 at the broker first. Upstox: cancel and replace (Open: its modify API). |
| 8 | 7 | The Execution workspace was labelled "Orders" in its tab and side bar, so it read as if execution did not exist. | **Fixed** — named Execution. |
| 9 | 2 | Market intelligence dashboard failed to draw when the engine had not produced "top" or "movers" yet. | **Fixed** — shows "Nothing yet". |
| 10 | 5 | Risk checks, sizing, stops and allocation cannot run from graphs yet. | **Open** — they can be drafted, checked and approved; binding them into risk, sizing and portfolio is phase 5 (risk graphs may only add refusals). |

| 12 | 7 | MT5 amend has been tested against the scripted broker only. | **Open** — to be shown on a demo account before relying on it live. |

## Evidence

* Backend: `tests/test_calc.py` (nodes, parser, safety, point in time per node, determinism, budgets, parity of every
  built-in, life cycle, bindings, graph strategy end to end), `tests/test_algos.py` (TWAP, iceberg with cap, pause on a
  refused child and resume, cancel, VWAP weights, POV, decision worked by an algorithm, amend).
* UI: `ui/tests/trading.cjs` (signal graphs: library, plain view with this bar's numbers, copy).
