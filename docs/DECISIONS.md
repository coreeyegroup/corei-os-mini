# COREI-OS-MINI — Owner Decisions after Document Index v1.1

These decisions were made by the project owner after the v1.1 baseline. Where they conflict with
the baseline documents, these decisions govern. Blueprint decisions DEC-01 … DEC-17 remain in force
except where amended below.

| DEC-26 | 11 Nov 2026 | **An MT5 server and its addresses are stored once, on the connection; accounts point to it.** One connection per provider × environment × server. | DEC-27 | 11 Nov 2026 | **Each MT5 account chooses how it uses its server's addresses**, switchable at any time without losing data: SERVER (the connection's ticked addresses in its order — default), FASTEST (the same, fastest by the latest latency test first) or ACCOUNT (its own ordered list, which must come from its server's addresses). An account's own list is kept when the mode is switched. One rule (`mt5_routing.py`) serves readiness, screens and the adapter. | New; keeps routing options open (more modes can be added to the same field). |
| DEC-28 | 11 Nov 2026 | **Latency is measured from the COREI server**, by TCP connect only (no MT5 handshake, no login, nothing sent): best and median of three attempts per address. Only public internet addresses are tested; private, loopback and reserved addresses are refused. Results are kept as append-only history per connection so routing can later use trends and, once the adapter exists, real order round-trip and slippage per account × address. | New. |
| DEC-29 | 11 Nov 2026 | **No option is narrowed at this stage.** Both MT5 connection methods stay available per connection (`adapter`: MTAPI_DIRECT — licensed SDK, no terminal — or TERMINAL_BRIDGE); own, firm and client accounts are all supported; e-mail, Telegram and webhook alerts are all supported. | DEC-30 | 11 Nov 2026 | **Facts the broker decides are read from the broker, not assumed.** Margin mode (hedging/netting), account group, leverage, stop-out, order/position caps and each symbol's rules (lot min/step/max, filling modes, stops level, trade mode) are stored with the time read and their source (BROKER or MANUAL). | DEC-31 | 11 Nov 2026 | **Four-eyes on LIVE changes**: adding addresses to a LIVE connection, creating or reactivating one, replacing a LIVE credential and LIVE one-step account set-up become change requests that a different person must approve.
